### What's new and fixed

**What this is**

- Same Soprano as [v1.1.5](https://github.com/AverWasTaken/soprano/releases/tag/soprano-v1.1.5), but your 26.3 game can join servers on other Minecraft versions (cc9f1dd)
- Pick the server's version with the new slider on the server list. Leave it on Auto and it figures it out by itself (29cdaa3)
- Uses the server version's fall damage and mining speed rules, so the bot doesn't plan with the wrong ones (d48f393)

**How to install**

- Download the `api` fabric jar and drop it in your `mods` folder. Nothing else to install, ViaFabricPlus is already inside the jar
- If you have the old ViaFabric mod, take it out
- Your game still has to be Minecraft 26.3. Only the server can be any version
- On 2b2t, set the slider to 1.21.4 by hand. Auto gets fooled there
- A version you set for one server in Edit Server still wins over the slider

**Everything in v1.1.5 is in here too**

- Schematic builder with a Schematics tab, ghost preview, and material gathering in survival
- Auto torch (`#autoTorch true`), self defense (on by default), and `#gather yes/no` before collecting blocks for a path
- Builder, pathing, lava, water and portal fixes. Full list on the [v1.1.5 release](https://github.com/AverWasTaken/soprano/releases/tag/soprano-v1.1.5)

**Good to know**

- This is a beta. Not everything got play-tested on every server version. If something acts weird, report it
