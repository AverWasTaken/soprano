### What's new since v1.1.7-nightly.10

**#gamer fixes**

- Lava knocks: when a mob hits the bot near a deadly drop, it now crouches right away and leans back from the edge, so a hit on a pillar top doesn't slide it into lava as easily. In the Nether, a mob two or more blocks up by a drop gets to come down to the bot instead of the bot pillaring up to it (6f5328a)
- In the Nether it no longer builds tall one block towers right next to a lava sea, where one hit drops it and all its stuff into the lava. Towers over solid ground still work (4b4210c)
- Knocked into lava, the bot now swims for the shore. Before, the fight code kept going from inside the lava: it crouched, raised the shield and aimed at the mob, so it sank and burned (9f30c9f)
- With no weapon it makes a wooden sword first, before the long walk for food. The walk back to its dropped items also gives up at 8 hp or less when it has nothing to heal with, even if nothing just hit it (946c366)
- After a respawn far from its last life's furnaces and crafting tables, it forgets them instead of walking all the way back for them (f69d22c)

**Plainer chat**

- Chat lines use plain words. "Task: Getting blocks for the path" and "Done in 12s." instead of "User Task Set: <...>" and "User task FINISHED". Status, coords, inventory and give lines lost the capitals and raw ids, mob and item names show as names, and pathing errors give one plain line in chat with the details in the log (10fbdaf)
- `#gamer` and the speedrun parts keep their play by play (crystals, beds, portals, eye throws, lava lake search) in the log now. Chat says "Next: <phase>" and one plain line per death (ddf389f)
- Help and command messages say Soprano instead of Baritone, and the crash message links to Soprano's issues. `#help` is in A-Z order, and command errors say what to do next, like "Unknown command: foo. Type #help for the list." (2004b8a)

**Trip toast**

- Y and N now also answer the toast with the inventory or a chest open. Search boxes (creative, anvil, recipe book) still get the letter (9299c16)
- The same words everywhere: "24 blocks" and "stone pickaxe", no more "about". "Got 24 blocks" stays up for 3 seconds, and only the question plays a sound
- If the toast or the task panel breaks, it says so in chat instead of quietly vanishing

**Good to know**

- This is a nightly. Expect bugs
- `#gamer` is still being worked on and isn't reliable yet. One test game with the pillar top, tower and sword fixes beat the game with 0 deaths in 1 h 18 min. It ran before the swim-for-the-shore fix and the chat cleanup. Other test games still died or got stuck in the Nether
- The game was started on Fabric, Forge 26.3-66.1.5 and NeoForge 26.3.0.101 into a world, with the inventory and pause menu opened. The last four fixes came after that check but don't change how the mod loads
- Y and N with the inventory open were checked in a test game. Other screens weren't
- The detailed lines that left chat are still in the game log
- If a run stops and says so, type `#gamer` and it picks back up
